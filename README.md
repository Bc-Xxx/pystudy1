# 🐍 Python 进阶练习

系统化的 Python 进阶学习仓库，从 OOP 到接口测试，每个阶段配套练习脚本与实战项目。

## 📚 内容体系

### 面向对象与装饰器
- 类与继承、多态实战
- 装饰器原理与应用
- 综合练习

### 网络请求
- Requests 基础与请求头构造
- Session 会话保持
- 文件上传、异常处理
- 综合练习：接口调用与数据解析

### 测试与数据处理
- **Pytest** 单元测试与接口测试
- 文件 / Excel / 接口处理能力

## 📂 目录结构

```
Day2/    # OOP、继承、装饰器、综合练习
Day3/    # Requests、Session、文件上传、异常处理、测试数据
...
```

## 🚀 环境准备

```bash
pip install requests pytest openpyxl
```

运行单个练习：

```bash
pytest Day3/test.py -v
```
